# LinkerMor

Telegram-бот обратной связи. Пользователь пишет боту, сообщения приходят в
рабочую группу, любой участник группы отвечает реплаем, и ответ уходит
пользователю.

## Как это работает

1. Пользователь нажимает **/start** и проходит **капчу**: решает пример,
   выбирая ответ кнопкой. На ответ даётся 3 попытки, после них пауза в минуту.
2. Бот присылает **приветствие**, а следом **рекламу**, если она включена.
3. Только после этого в рабочую группу приходит карточка 🆕 Новый
   пользователь с именем, @username и ID.
4. Всё, что пользователь пишет дальше, бот **копирует** в группу: текст, фото,
   видео, файлы, голосовые, кружки, стикеры. Жирный, курсив, подчёркнутый,
   спойлеры, ссылки и премиум-эмодзи сохраняются как есть. Под каждой копией
   есть кнопки `👤 Имя · ID` и `🚫 Бан`.
5. Любой участник группы (хоть 50 человек) отвечает **реплаем** на сообщение
   пользователя или на карточку, сколько угодно раз. Бот копирует ответ
   пользователю со всем форматированием и ставит 👍 на сообщение в группе:
   так все видят, что ответ ушёл. Если пользователь остановил бота, в группе
   появится сообщение об этом.
6. Если пользователь ответит реплаем на ответ поддержки, его сообщение
   придёт в группу реплаем на тот самый ответ, и переписка не теряется.

## Антифлуд

* **От пользователей.** По умолчанию можно отправить не больше 3 сообщений
  за 10 секунд. Дальше бот на 30 секунд перестаёт пересылать сообщения этого
  человека, один раз предупреждает его и пишет в группу, кто флудит. Альбом
  считается одним сообщением. У нажатий /start свой отдельный счётчик. Все
  числа меняются в админке.
* **От бота.** Каждое исходящее сообщение проходит через общий ограничитель
  с лимитами Telegram: около 25 сообщений в секунду всего, не больше 3 за
  2 секунды в один личный чат и 20 в минуту в группу. Если Telegram
  всё же попросит подождать, бот подождёт и отправит снова. Сообщения в один
  чат уходят строго по порядку.
* **Рассылка** идёт медленнее общего лимита, поэтому ответы поддержки не
  ждут, пока она закончится.

## Админка

В личке бота: **/admin**. Всё делается кнопками.

| Раздел | Что можно |
|---|---|
| 👋 Приветствие | прислать любое сообщение: текст, фото, видео, GIF, файл, с форматированием и премиум-эмодзи; посмотреть; вернуть стандартное |
| 📢 Реклама при старте | задать, включить или выключить, удалить |
| 📨 Рассылка | прислать сообщение, посмотреть, как его увидят пользователи, выбрать, кому слать (всем, активным за 7 или 30 дней), подтвердить; прогресс виден на ходу, рассылку можно остановить. Бот напомнит, если прошлая рассылка была меньше суток назад |
| 👥 Рабочая группа | выбрать или сменить группу кнопкой, проверить связь |
| 🧩 Капча | включить или выключить |
| 🛡 Антифлуд | лимит, окно и длительность паузы кнопками − / + |
| 🚫 Баны | список, разбан кнопкой, бан по ID |
| 📊 Статистика | пользователи, активность, баны, число сообщений |
| 👮 Админы | только для владельца: добавить по ID или по пересланному сообщению, снять |

### Команды

В меню бота есть только `/start`. Служебные команды ниже в меню не
показываются и работают только у админов бота. Остальным бот на них не
отвечает вообще и никуда их не пересылает (`/id` доступна всем участникам
рабочей группы).

| Где | Команда | Что делает |
|---|---|---|
| группа | `/id` реплаем | показать ID пользователя |
| группа и личка | `/ban ID [причина]` | забанить; в группе можно реплаем на сообщение |
| группа и личка | `/unban ID` | разбанить |
| группа | `/setgroup` | сделать эту группу рабочей |
| личка | `/admin`, `/cancel` | админка, отмена ввода |

Узнать ID проще всего так: нажмите кнопку `👤 Имя · ID` под сообщением
пользователя в группе.

Сообщения забаненного пользователя бот не пересылает в группу. Ответы
забаненным при этом по-прежнему доставляются.

## Установка

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Узнайте свой Telegram ID, например у [@userinfobot](https://t.me/userinfobot).
3. На сервере:

   ```bash
   git clone https://github.com/dalmatinec/LinkerMor.git && cd LinkerMor
   cp .env.example .env    # вписать BOT_TOKEN и OWNER_IDS
   docker compose up -d --build
   ```

   Без Docker понадобится Python 3.11 или новее:

   ```bash
   python -m venv .venv && .venv/bin/pip install -r requirements.txt
   .venv/bin/python -m bot
   ```

4. Добавьте бота в рабочую группу и **сделайте его админом**. Без этого
   Telegram не показывает боту команды `/id` и `/ban` в группе. Реплаи на
   сообщения бота доходят и без прав админа. Права нужны минимальные:
   удалять и закреплять ничего не требуется.
5. В личке бота откройте `/admin` → 👥 Группа → 📌 Выбрать.
   Или напишите `/setgroup` в самой группе.

Если запросы к Telegram с сервера обрываются по таймауту, бот не падает:
он ждёт и пробует снова. Если Telegram с сервера недоступен совсем,
укажите в `.env` прокси: `PROXY=socks5://user:pass@host:1080`.

Данные хранятся в SQLite, в файле `data/bot.db`. Резервная копия это
просто копия этого файла.

Обновление:
`git pull && docker compose up -d --build`

## Премиум-эмодзи

Бот копирует сообщения и пересылает всю разметку целиком, включая
премиум-эмодзи. Покажет ли их Telegram в сообщении от бота, решают правила
самого Telegram для ботов. Если Telegram этого не разрешит, на их месте
будут обычные эмодзи. Остальное форматирование сохраняется всегда.

## Разработка

```bash
pip install -r requirements-dev.txt
pytest          # тесты прогоняют настоящий диспетчер с поддельным Telegram
ruff check bot tests
```

| Файл | Что внутри |
|---|---|
| `bot/__main__.py` | запуск |
| `bot/handlers/user.py` | /start, капча, сообщения пользователя |
| `bot/handlers/group.py` | ответы из рабочей группы |
| `bot/handlers/moderation.py` | бан, разбан, /id, кнопки под сообщениями |
| `bot/handlers/admin.py` | админка |
| `bot/relay.py` | копирование между пользователем и группой |
| `bot/throttle.py` | лимиты исходящих сообщений |
| `bot/flood.py` | антифлуд пользователей |
| `bot/broadcast.py` | рассылка |
| `bot/db.py`, `bot/settings.py` | хранилище и настройки |
