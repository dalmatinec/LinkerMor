# Развёртывание

Пошагово, с расчётом на то, что всё делается с телефона.

---

## 1. Подготовка бота

1. Откройте [@BotFather](https://t.me/BotFather), команда `/newbot`.
2. Сохраните токен — он понадобится один раз.
3. Отключите режим приватности, иначе бот не увидит сообщения в группах:
   `/mybots` → ваш бот → **Bot Settings** → **Group Privacy** → **Turn off**.
4. Узнайте свой числовой идентификатор: напишите
   [@userinfobot](https://t.me/userinfobot), он ответит числом.

Без пункта 3 бот будет видеть только команды, и антиспам с триггерами
работать не станут.

---

## 2. Сервер

Подойдёт любой VPS: 2 ГБ памяти, 25 ГБ диска, Ubuntu 24.04. Подробнее о
выборе — в [GUIDE.md](GUIDE.md).

Подключитесь по SSH (Termius на телефоне) и выполните:

```bash
# Docker
curl -fsSL https://get.docker.com | sh

# Проект
git clone https://github.com/dalmatinec/LinkerMor.git /opt/linkermor
cd /opt/linkermor
cp .env.example .env
```

---

## 3. Настройка

Откройте `.env` (`nano .env`) и заполните четыре строки:

```
BOT_TOKEN=токен от BotFather
OWNER_IDS=ваш числовой id
POSTGRES_PASSWORD=любой длинный пароль
WATCHDOG_URL=адрес внешнего сторожа, можно оставить пустым
```

Остальное можно не трогать.

**Внешний сторож.** Заведите бесплатную проверку на
[healthchecks.io](https://healthchecks.io), скопируйте её адрес в
`WATCHDOG_URL`. Бот дёргает адрес раз в минуту, пока всё исправно; если
сигналы прекратятся, служба напишет вам. Без этого падение сервера
останется незамеченным.

---

## 4. Запуск

```bash
docker compose up -d
docker compose logs -f bot
```

В логе должно появиться «бот запущен». Вы получите личное сообщение от
бота о запуске — это подтверждение, что владелец определён верно.

Остановка — `docker compose down`, перезапуск — `docker compose restart bot`.

---

## 5. Подключение чата

1. Добавьте бота в группу.
2. Выдайте права администратора: удаление сообщений, блокировка
   участников, приглашение по ссылке, закрепление сообщений.
3. Напишите боту в личку `/start` — чат появится в списке.

Права можно выдать не все: бот сообщит, какого именно не хватает, когда
оно понадобится.

---

## 6. Обновление

```bash
cd /opt/linkermor
git pull
docker compose up -d --build
```

Миграции применяются сами при старте контейнера.

### Обновление без SSH

Настройте GitHub Actions, и обновление сведётся к нажатию Merge в
приложении GitHub. Заготовка лежит в `.github/workflows/deploy.yml`:
добавьте в настройках репозитория секреты `SSH_HOST`, `SSH_USER` и
`SSH_KEY`.

---

## 7. Резервные копии

Копия создаётся раз в сутки и приходит вам в Telegram файлом. Команда
`/backup` делает копию немедленно.

Восстановление:

```bash
gunzip -c linkermor-20260919-030000.sql.gz | \
  docker compose exec -T postgres psql -U linkermor -d linkermor
```

---

## 8. Если что-то пошло не так

| Симптом | Причина и что делать |
|---|---|
| «Telegram отверг токен» | опечатка в `BOT_TOKEN` или токен отозван |
| «связь не установлена, повторяю» | нормально: бот сам пробует снова, до 30 попыток |
| «не удалось связаться за отведённое число попыток» | проверьте `curl -I https://api.telegram.org` с сервера |
| Бот молчит в группе | не отключён Group Privacy у @BotFather |
| Команды не работают | у человека нет роли; проверьте через `/start` в личке |
| Не приходят уведомления владельцу | напишите боту `/start` в личку — Telegram не даёт писать первым |
| Кончилась память | посмотрите `docker stats`; при 1 ГБ добавьте swap |

Логи: `docker compose logs -f bot`. Состояние: команда `/health`.
